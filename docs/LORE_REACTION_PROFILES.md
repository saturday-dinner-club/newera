# 동봉 로어의 초기 반응 수치

2026-10-25 기준. 기존 인물의 말투·참여 성향과 시작 장면을 바탕으로 설정한 초기값이다. 작성 원본 JSON의 `reactionProfile`과 `spawns[].arousal`이 기준이며, 이후 실제 흥분도는 사건 해석으로 바뀐다. 기본 제공 극장에도 같은 수치를 적용한다.

기본 반응 속도는 평소 판단 리듬, 말수 성향은 대화에 자주 참여하려는 성향, 흥분도는 시작 시점의 긴장·기대·각성 정도다. 활발한 인물에게 기회가 더 자주 돌아오지만 조용한 인물의 의견이나 행동을 금지하지 않는다. 초기 흥분도는 5~35로 두어 극단적인 흥분 상태나 예정된 갈등을 만들지 않았다. 계산식과 기회·저장 규칙은 [반응 속도 계약](REACTION_SPEED_DESIGN.md)을 따른다.
